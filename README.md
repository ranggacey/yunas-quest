# Yuna's Quest — RPG Dunia Pixel

RPG 2D top-down dengan procedural pixel art (gak perlu file gambar eksternal).

## Fitur
- 🗺️ Map tile-based (40x30) dengan desa, hutan, air, jembatan
- 👤 Player movement (D-Pad HP + WASD keyboard)
- 💬 NPC dialog system
- ⚔️ Enemy slimes, bisa dikerok
- 🗡️ Combat system (attack + level up)
- 📦 Chest dengan reward
- 🌳 Pohon, pagar, rumah, bunga — semua procedural draw
- 📱 Responsive landscape buat HP + desktop

## Cara Main
- **HP:** D-Pad tombol ▲▼◀▶ / WASD / Arrow
- **Desktop:** WASD / Arrow keys
- **A / Spasi / Enter:** Interaksi / dialog next
- **B:** Menu info

## Tech Stack
- HTML5 Canvas (pure, gak pake library)
- JavaScript vanilla
- CSS (responsive, glassmorphism UI)
- **Gak pake tile asset — semua digambar procedural pake kode**

## Run
```bash
# Buka aja index.html di browser
open index.html
# Atau serve
npx serve .
```
